# Changelog: Brilian DMS

Semua perubahan penting pada proyek ini akan dicatat dalam dokumen ini. Format didasarkan pada *Keep a Changelog*.

## [1.0.0] - 2026-03-30
### Added
- Rilis perdana arsitektur *Single-Binary On-Premise* berbasis Golang dan React + Rust Wasm.
- Integrasi Zero-Source-Code dengan Docker `FROM scratch`.
- Fitur *Multi-Document Comparison* dan tanya-jawab kontekstual menggunakan Enterprise Cloud AI API (*Zero Data Retention*).
- Implementasi *Layout-Aware OCR* dan penyimpanan hybrid PostgreSQL (`tsvector` & `pgvector`).
- Modul *Workflow* dokumen terpadu lengkap dengan pelacakan SLA dan *audit trail*.
